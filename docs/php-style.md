# PHP書式の小規約

既存コードを一括整形せず、変更対象を明示して小さく適用します。今回の対象は`ApifyClient`、`ApifyFlightSearch`、`ApifyHotelSearch`、`ApifyDestinationSearch`の4クラスです。

- インデントは半角スペース4つ。PHP開始タグ、declare、namespace、use、classの間は空行で区切ります。
- メソッドの本文は改行し、メソッド間に空行を置きます。複数の文を1行に詰めません。
- 長い配列は1項目ずつ改行し、カンマの後と`=>`の両側に空白を入れます。長い呼出は引数や入れ子の単位で改行します。
- 既存の単文ifは制御構造を変えず、本文を次行にインデントして配置します。波括弧や末尾カンマの一括追加は今回の範囲外です。
- 新規の処理クラスは`declare(strict_types=1);`をPHP開始タグ後の空行に続けて記述します。既存ファイルの宣言有無は書式修正では変更しません。未宣言ファイルへの追加はスカラー引数の型変換に影響するため、呼出元・テストを確認する別変更として扱います。
- 書式変更に変数名・リテラル・処理順・型宣言・条件・例外処理の変更を混ぜません。

今回の4ファイルは`token_get_all()`で空白・コメントを除いたトークン列が変更前と一致することを確認しています。構文検査と既存テストも実行します。全PHPファイルの書式統一やstrict化が完了したという意味ではありません。
